# EMORA roadmap

## Phase 1 — MVP
- Telegram authentication
- Payment confirmation
- 6–10 categories
- 10–15 templates/category
- Site editor fields
- Image upload
- Public slug
- Publish/unpublish
- Mobile responsive public pages

## Phase 2 — AI
- AI text generation
- Rewrite tone
- AI section generation
- AI design commands
- Smart image captions
- Music/video/gallery blocks
- Countdown
- Confetti/particles
- Multilingual generation

## Phase 3 — PRO AI
- Conversational site builder
- Live preview
- Structured site JSON
- AI tool calling: add_section, edit_text, set_theme,
  add_gallery, add_countdown, add_music, publish
- Undo/redo
- Version history
- Custom domain

## Phase 4 — Platform
- Template marketplace
- Designer accounts
- Affiliate/referral
- Business/agency workspace
- Analytics
- A/B testing
- SEO
- Automated domain setup
